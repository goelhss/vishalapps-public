# CarMedia Data Deletion

CarMedia does not require a CarMedia account. Most app data stays on the device and can be removed directly by the user.

## Delete a Google Drive backup

1. Open CarMedia.
2. Open **Settings** and then **Backup Settings**.
3. Under **Backup in Google**, tap **Delete Google Drive backup**.
4. Confirm the deletion.
5. Tap **Disconnect Google account** if the account should no longer be connected to CarMedia.

This permanently deletes CarMedia's private backup from the connected account's hidden Google Drive app-data folder. CarMedia does not retain a server-side copy.

## Delete data stored on the phone

- Use the delete or clear controls next to saved library data, music data, recordings, credentials, and other configurable features.
- To remove all local CarMedia data, use Android **Settings > Apps > CarMedia > Storage > Clear storage**, or uninstall CarMedia.
- Password-manager entries are controlled by the password manager selected in Android settings and must be removed there.

Deleting local data removes settings, indexes, cached values, encrypted local credentials, and other app-private data from that phone. Files that the user created or selected outside CarMedia, including exported `.cmcfg` files and personal media, are not deleted automatically.

## Retention

CarMedia does not operate a developer server that stores user data. A private Google Drive backup remains until the user replaces or deletes it. Data stored locally remains until the user clears it or uninstalls the app.
